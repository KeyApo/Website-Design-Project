# Website-Design-Project
A project in which I showcase my skills in HTML and CSS for ECPI that features original artwork through an online store.

# Title and Overview
# NeonReflections 
A fandom-based online store that sells prints and merchandise of fan work and original characters from the artist NeonReflections (aka me, Keymy Aponte). All the artwork and shop galleries will be presented in a sleek and fun pseudo-Windows Vista aesthetic to draw in potential buyers and fans of all kinds. 

# Feature roadmap 

Week 1 (August 2nd – August  9th) - Set up general site layout for each page including organization of information, simple containers of text, makings of a banner, and image placeholders 

Week 2 (August 10th – 16th) - Start including e-commerce setup, including adding things to cart, purchasing said items, and removing items from cart alongside displayed prices on products. A form should be established to include user data needed to ship items out. 

Week 3 (August 17th – 23rd) - Start making aesthetic choices that govern the site and replace placeholder images, containers, and text with proper information. The storefront will have filters in place, and the artist blog will slowly be built to include status updates and potential news. 

Week 4 (August 24th – August 31st) - The week will be spent polishing the website’s overall look and functionality before being unveiled in August 31st.
